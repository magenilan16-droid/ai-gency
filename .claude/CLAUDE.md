# AI-gency — Travel Planning Web App

## מה הפרויקט
פלטפורמת תכנון טיולים חכמה. לקוחות נכנסים, מכניסים יעד + תקציב, ומקבלים תוכנית טיול מלאה עם אטרקציות, חלוקת תקציב, ולינק לשיתוף.

## Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **AI**: Claude API (Anthropic) — לייצור תוכניות טיול
- **Deploy**: Vercel

## מבנה עמודים
```
/                → Landing page (הסבר + CTA)
/plan            → כלי תכנון הטיול (הכנסת יעד + תקציב)
/trip/[id]       → תוצאת הטיול (ניתן לשיתוף)
```

## פיצ'רים ליבה
1. חיפוש יעד + תאריכים + תקציב
2. AI מייצר תוכנית יום-יום עם אטרקציות
3. חלוקת תקציב לקטגוריות (לינה, אוכל, טיסות, אטרקציות)
4. לינק שיתוף לטיול

## חוקים
- UI נקי ומינימלי — לא לעמוס
- Mobile-first תמיד
- RTL support לא נדרש (האפליקציה באנגלית)
- אל תשנה את מבנה ה-App Router
